 ##🌿 AI Tomato Leaf Disease Detection

##Overview:

An AI-powered web application that detects diseases in tomato leaves using a Convolutional Neural Network (CNN).

The user uploads an image of a tomato leaf, and the system predicts:

- Disease Name
- Prediction Confidence
- Suggested Solution

## Features

1. Upload tomato leaf images

2. AI prediction using CNN

3. Confidence score

4. Disease information
